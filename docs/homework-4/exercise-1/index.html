01 Definitions and Knuth’s mean recurrence

For observations x₁,…,xₙ, write μₙ = (1/n) Σᵢ₌₁ⁿ xᵢ and SSₙ = Σᵢ₌₁ⁿ (xᵢ − μₙ)². Here μₙ is the sample mean; SS is the centered sum of squares, not Σxᵢ².

Splitting off the new observation gives nμₙ = (n−1)μₙ₋₁ + xₙ. Subtract nμₙ₋₁ and divide by n to obtain Knuth’s mean recurrence:

μₙ = μₙ₋₁ + (xₙ − μₙ₋₁)/n.

Only the previous mean, count and new value are needed. The unbiased sample variance is sₙ² = SSₙ/(n−1), n ≥ 2. The descriptive variance SSₙ/n uses a different denominator.

02 Deriving the SS and variance recurrences

For n ≥ 2, let δₙ = xₙ − μₙ₋₁, so the mean shifts by δₙ/n. Recenter the first n−1 observations, then add the new squared deviation:

SSₙ = Σᵢ₌₁ⁿ⁻¹ [(xᵢ − μₙ₋₁) − δₙ/n]²
+ (xₙ − μₙ)².

The old deviations sum to zero, Σᵢ₌₁ⁿ⁻¹ (xᵢ − μₙ₋₁) = 0, so the cross term vanishes. The shift adds (n−1)δₙ²/n² to their SS; the new deviation is xₙ − μₙ = (n−1)δₙ/n. Hence:

SSₙ = SSₙ₋₁ + [(n−1) + (n−1)²]δₙ²/n²
= SSₙ₋₁ + ((n−1)/n)δₙ²
= SSₙ₋₁ + δₙ(xₙ − μₙ).

Dividing by n−1 and substituting SSₙ₋₁ = (n−2)sₙ₋₁² gives the sample-variance recurrence, for n ≥ 3:

sₙ² = ((n−2)/(n−1))sₙ₋₁² + δₙ²/n.

Initialize μ₁ = x₁, SS₁ = 0; s₁² is undefined. The first valid variance is s₂² = SS₂ = (x₂−x₁)²/2. No recurrence uses an undefined s₁².

04 Correctness, numerical stability and conclusions

Independently, Σxᵢ = 40 and Σ(xᵢ−5)² = 32 verify the worked example. For 10¹² + [1,2,3,4], the exact SS is 5. JavaScript’s subtraction Σxᵢ² − nμₙ² yields 0 for this ordering, while Welford yields 5: subtracting two large, nearly equal numbers loses the small spread.

Welford uses centered differences in one pass, O(n) time and O(1) state. It reduces cancellation but cannot recover precision already lost when inputs are represented as floating-point numbers. Tests compare every prefix with an independent two-pass calculation, including constants, fractions, negatives, initialization and overflow.

The recurrence computes SS; dividing by n−1 supplies the unbiased estimator under iid sampling with finite variance. Unbiasedness follows from E[SSₙ] = (n−1)σ², not from numerical stability. Exercise 2 reuses this module to study both estimators’ sampling variability.
