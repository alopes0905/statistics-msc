01 Definitions and integration principles

For a bounded function on [a,b], a domain partition a=x₀<⋯<xₙ=b gives a tagged sum Σᵢ f(ξᵢ)Δxᵢ. Left, right and midpoint rules use the left endpoint, right endpoint or center of each cell. I use midpoint sampling by default. These sampled heights are not the infima or suprema required for lower and upper Darboux sums.

For nonnegative measurable f, let M(t)=λ({x∈[a,b]:f(x)>t}), where λ denotes interval length (Lebesgue measure). Since f(x)=∫₀∞ 1{t<f(x)}dt, exchanging the nonnegative integrals by Tonelli gives the layer-cake identity:

∫ f(x)dx = ∫₀∞ M(t)dt.
For 0≤f≤H: ∫ f = ∫₀ᴴ M(t)dt.

Partition the value axis with Δt=H/K. Because M is nonincreasing, the following range sums enclose the integral in exact arithmetic:

Lₖ = Δt Σⱼ₌₁ᴷ M(jΔt),
Aₖ = Δt Σⱼ₌₀ᴷ⁻¹ M((j+½)Δt),
Uₖ = Δt Σⱼ₌₀ᴷ⁻¹ M(jΔt);
Lₖ ≤ ∫f ≤ Uₖ.

Every example here is nonnegative. A signed integrable function requires f=f⁺−f⁻ and separate integrals of its positive and negative parts. The measurable-function framework and agreement with proper Riemann integration follow Wilkins, §§8.3–8.6.

Where the preimage measures come from

For x², solving x²>t gives (√t,1]. For sine, the preimage is (arcsin(t),π−arcsin(t)). For |x−½| it is two outer intervals, with total length 1−2t. For the two step functions, the lengths follow directly from the pieces. Empty superlevels have measure zero; negative thresholds include the whole domain.

For analytical M, computing all three range sums uses 2K+1 measure calls; the domain method uses K function calls. Sinc adds O(K log(1/ε)) evaluations for root tolerance ε. Mathematical convergence, quadrature error, algorithmic work and measured runtime are distinct quantities.

The enclosure telescopes: Uₖ−Lₖ=(H/K)[M(0)−M(H)]≤H(b−a)/K. Thus both range bounds converge. Smooth midpoint domain sums typically have O(K⁻²) error, but jumps and inverse-function corners affect observed orders. For x², the exact domain midpoint error is 1/(12K²); M(t)=1−√t has a corner. Aligned step partitions or piecewise-linear functions can have exact sampled sums. Lower error at equal K alone establishes no efficiency advantage.

04 Pathological functions and conclusions

Dirichlet: sampling cannot establish an integral

Let D(x)=1 on rational x and 0 on irrational x in [0,1]. Both sets meet every interval, so every lower Darboux sum is 0 and every upper sum is 1: D is not Riemann-integrable. The rationals are countable with measure zero, giving Lebesgue integral 0.

The exact rational midpoint family (2i+1)/(2K) gives tagged sums 1. The symbolic irrational family (i+√2/2)/K, i=0,…,K−1, gives sums 0. Neither family establishes Riemann convergence. Every finite JavaScript Number is a rational binary fraction; the program uses rational integer indices and symbolic irrational labels, not a floating-point rationality oracle.

Thomae: discontinuities on a null set

For reduced p/q, define T(p/q)=1/q; set T(x)=0 at irrational x. Rational points are discontinuities. At an irrational point, excluding the finitely many rationals with q≤Q in a small neighborhood leaves values <1/Q, proving continuity there. Hence the discontinuity set is countable, and the Lebesgue criterion gives Riemann integral 0; its Lebesgue integral is also 0.

The code reduces the rational midpoint numerator and denominator using integer GCD. On the power-of-two grids below, every reduced denominator is 2K, so the finite rational sums equal 1/(2K) and approach zero. This demonstration complements the analytical integrability argument.

The improper singular case

For f(x)=1/√x on (0,1], ∫ε¹ f=2−2√ε→2. It is unbounded and has no proper Riemann integral on [0,1]; its improper Riemann and Lebesgue integrals agree. Midpoint sampling never evaluates f(0).

Solving x⁻¹ᐟ²>t gives M(t)=1 for 0≤t≤1 and M(t)=t⁻² for t>1. Therefore:

∫₀∞ M(t)dt=1+∫₁∞ t⁻²dt=2;
∫₀ᵀ M(t)dt=2−1/T, T≥1;
omitted value-axis tail=1/T.

Fixed K=1,024, varying T: increasing T reduces cutoff bias but also widens each value bin. Quadrature and cutoff error must both be considered.
