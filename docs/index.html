02 / Methodology

Understanding comes first.

A consistent standard for the work,
from the first definition to the final result.

  1. 01

    Start with the mathematics

    State definitions, derive the method, and make assumptions explicit before writing code.

  2. 02

    Build from scratch

    Implement statistical methods in standard JavaScript, without external statistical, numerical, or visualization libraries.

  3. 03

    Think beyond one dataset

    Design general algorithms with clear inputs, consistent outputs, and deliberate treatment of edge cases.

  4. 04

    Keep the work transparent

    Show important source code beside its explanation, so each implementation can be read and understood on the page.

  5. 05

    Make ideas explorable

    Use interactive demonstrations and native browser graphics to connect mathematical reasoning with observed behavior.

  6. 06

    Verify and acknowledge

    Test known results and invariants, discuss limitations, and attribute the sources that inform the work.

03 / Context

A working record
of understanding.

This independent student project supports the Statistics course within an MSc in Cybersecurity. It is a place to develop, test, and explain the reasoning behind each homework assignment.

The website uses HTML, CSS, and vanilla JavaScript. Every published assignment will have its own accessible URL, with its mathematical explanation and important implementation visible together.

The foundation is ready. Academic content will follow the professor’s actual assignments.
